# Cadeia de confiança para a NFS-e nacional

Coloque aqui o pacote PEM de raízes ICP-Brasil verificado para o ambiente de homologação, com o nome `icp-brasil-ca.pem`. API e worker montam esta pasta em modo somente leitura. O arquivo precisa ser mantido atualizado pelo operador; sua ausência mantém a emissão bloqueada.

O certificado A1 da empresa é enviado pelo cadastro da empresa e armazenado cifrado no banco. Ele não deve ser colocado nesta pasta.
